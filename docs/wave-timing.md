# 水位场触发机制：时间关系

**一句话**：每次发言是一个脉冲，多条脉冲线性叠加成一条随时间涨落的水位 `A(t)`；
`A(t)` 过阈值才允许下一次主动开口，开口后泄流清零。次数仍由每日额度管，水位只管时机。

## 形式化

```
K(τ) = 0                               τ < d          # 不打扰期（硬下限）
     = u · e^(1-u),  u = (τ − d)/(θ − d)  τ ≥ d        # 平移 Gamma(2)：峰在 θ、峰高 1
A(t) = Σ wᵢ · K(t − tᵢ)                              # 线性叠加
fire(t) ⟺ A(t) ≥ thr ∧ t − max(tᵢ, drained) ≥ 0
```

- `w` 是权重，**必须小于 `thr`**：否则单条消息的峰就能过线，阈值形同虚设，机制退化成固定延时。
- 不打扰期的锚点是**最后一条发言（任一方）**，不是每条脉冲各自算。
- 泄流点是「上一次真发」，不引入额外状态——回放天然可复现。

## 起爆延迟

```
Δ = max(d, 水位达标所需时间)
```

两条分工：`d` 管最早，水位管还要等多久。哪一项是瓶颈取决于对话密度——见 C2 与 C2b。

## 时间线案例

> 参数：delay=30min，peak=45min，thr=0.5，w_user=0.4，w_self=0.25，idleExempt=180min。
> 符号：· 水位 0，▁ <0.25，▄ <0.5，▆ <0.75，█ ≥0.75；▲ = 第一次跨过阈值并泄流，○ = 冷场豁免（水位不参与）。每格 5 分钟。

### C1 单条消息：永不触发

`w_user < thr` 的直接后果。孤立的一句话不够开一次口，音量不会因为「等得久」变大。

```
脉搏   0
A(t)   ·······▄▄▄▄▄▄▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁
命中                                 
       0     30    60    90    120     (min)
```
→ 全程不触发；峰值 0.40 < 阈值 0.50

### C2 两条相隔 10 分钟：+42 分钟开口

叠加够了才开口。命中窗口有起有落：早了水还没涨上来，晚了又退回去。

```
脉搏   0, 10
A(t)   ········▄▆····················
命中           ▲                     
       0     30    60    90    120     (min)
```
→ 命中 t = +42min

### C2b 两条相隔 25 分钟：水位成了瓶颈

最后一条之后满 30 分钟时水还不够——第一条已经退到 0.28，第二条才刚起步。还要再等几格才过阈值：这时决定开口时刻的是水位，不是不打扰期。

```
脉搏   0, 25
A(t)   ···········▄▆·················
命中               ▲                 
       0     30    60    90    120     (min)
```
→ 命中 t = +59min

### C3 密聊五条：更晚、更久、仍只算一次

叠加把起爆点往后推、把高水位拉宽，但只泄流一次——叠加再多也只算一个。

```
脉搏   0, 2, 5, 8, 12
A(t)   ·········█····················
命中           ▲                     
       0     30    60    90    120     (min)
```
→ 命中 t = +42min

### C3b 同一个场景，把不打扰期压到 10 分钟

delay 一收短，起爆点立刻提前到 +22 分钟——起爆延迟的公式是第一句话命脉：**最后一条 + max(不打扰期, 水位积累时间)**。

```
脉搏   0, 2, 5, 8, 12
A(t)   ·····█························
命中       ▲                         
       0     30    60    90    120     (min)
```
→ 命中 t = +22min

### C4 会话结束 → 泄流 → 下一轮重新蓄水

泄流把 t=42 之前的脉冲全部作废；同样的两条新消息重新蓄水，间隔由对话本身决定，不是固定节拍。

```
脉搏   0, 10, 60, 70
A(t)   ····················▄▆········
命中                       ▲         
       0     30    60    90    120     (min)
```
→ 命中 t = +102min

### C5 冷场豁免：最后一条在 4 小时前

水位早已归零，但这不是「刚聊完别打扰」，是「没人说话」。豁免后交给每日额度，否则普通关心永远发不出去。

```
脉搏   -240, -238
A(t)   ······························
命中   ○○○○○○○○○○○○○○○○○○○○○○○○○○○○○○
       0     30    60    90    120     (min)
```
→ 全程不触发；豁免裁定放行、水位不参与

### C6 自己说的话也算，但更轻

她说完一句，水也涨一点，但权重 0.25：自己开口更该克制，不能靠自言自语攒出下一次发言。

```
脉搏   0(自), 10(自)
A(t)   ········▁▄▄▄▄▄▄▄▁▁▁▁▁▁▁▁▁▁▁▁▁▁
命中                                 
       0     30    60    90    120     (min)
```
→ 全程不触发；两条自说自话仍不够开口

### C7 夜里不积压

晚上 23 点聊完，静默到早上 8 点：水位已经回到 0，不会一醒来就被补发的热情吵到。

| 经过时间 | A(t) |
|---|---|
| 0.5 小时 | 0.000 |
| 1 小时 | 0.676 |
| 2 小时 | 0.044 |
| 4 小时 | 0.000 |
| 7 小时 | 0.000 |

→ 7 小时后 A = 0（阈值 0.5）

## 与固定节拍的对比

同一份真实数据（私聊池 353 条消息 / 5 天，tick 5 分钟）下，相邻两次「可以开口」的间隔变异系数：

| 机制 | 间隔 CV | 说明 |
|---|---|---|
| 固定冷却 + 固定最小间隔 | ≈ 0.00 | 每个间隔都一样长，用户读作机器 |
| 固定 2h + 0–20min 抖动 | ≈ 0.04 | 抖动只加在常数上，CV 仍是常数级 |
| 水位场 | **1.46** | 间隔由对话本身的形状决定 |

CV 的判读：不是越大越好，而是**它应该由输入产生**。0 意味着「机制在帮我决定」，1.46 意味着「我们的对话在决定」。

水位场在真实数据上的输出（同 5 天）：

```
水位命中 16 次（3.2/天）
拦下 450 个 tick：不打扰期内 195，过了不打扰期但水位不够 255
冷场豁免 975 个 tick（68%）——那部分不归水位管，交给每日额度
```

## 参数

| 参数 | 值 | 作用 |
|---|---|---|
| `delayMin` | 30 | 硬不打扰期，从最后一条发言算起 |
| `peakMin` | 45 | 单条脉冲到峰的时间；必须 > delay |
| `thr` | 0.5 | 触发水位 |
| `wUser` | 0.4 | 用户消息权重，**必须 < thr** |
| `wSelf` | 0.25 | 自己发言权重 |
| `horizonH` | 24 | 只累加这么久内的脉冲 |
| `idleExemptMin` | 180 | 最后一条超过这么久就不拦（冷场豁免） |
