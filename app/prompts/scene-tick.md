【定时检查】

先看手上有没有正事：在跑的任务、待审批的计划、到点的节点、答应过的跟进。
只有这几种情况开口，按 `skills/reporting/SKILL.md` 一次说清：
- 有可交付的结果
- 有真需要他拍板的决策、要他给的权限或资源
- 任务卡住或有风险
- 确实做不了

若数据产出: 看 Working Agent 是否把结果落到了 `shared/outputs/task-<id>/`，汇报里给宿主绝对路径；只在聊天里报数字不算结果。
常规进度、方向确认、方案讨论都不算开口理由；方向由任务审批把关。
只是常规进度、没有新信息：不说，记进任务。
任务有 done / failed / blocked 要汇报：任务号 + 结论 + 产出绝对路径 + 验收方式；同一批合并成一条，**只发主聊天**（`chat list` 里标 [主聊天] 的，状态区也会写），不发群聊或任务来源池。
真没事：不说，chat（action=skip），reason 写一句为什么。

不为了「保持存在感」而开口；不寒暄、不找谈资、不递话头、不抖机灵。
唤醒消息底下「状态」那几行先扫一眼：连着 N 次醒着没事，就继续沉默，别硬找话说。
