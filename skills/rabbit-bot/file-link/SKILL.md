# 上传文件拿短链（upl）

## 什么时候用

- 他说「发我个链接」「这图给我看看」「跑出来的报告放哪」
- 要把产物交给别的 agent 或贴进聊天
- 图片/截图/PDF/音频/视频都行，**上限 50MB**

**不要用**的时候：文件里有凭据、隐私信息、合同、身份证、聊天记录。
桶是**公共读**——任何人拿到 URL 就能看，短链也不设过期时间。

## 一条命令

```
/work/bin/upl <文件>
```

只打印一行，例如 `https://s.hollway.top/cQ4ygy.txt`。这行就是交付物，直接发给他。

- 换名字（决定扩展名和 Content-Type）：`/work/bin/upl /work/files/x.bin --name 报告.pdf`
- 要字段：加 `--json`，返回 `{url,key,size,content_type,s3}`
- 探活：`/work/bin/upl --status`

`upl` 已登记免审，不会弹审批。

## 交出去之前先验一次

```
curl -sS -o /dev/null -w "%{http_code} %{redirect_url}\n" <短链>
```

期望 `302`，跳转到 `imagevault.tos-cn-guangzhou.volces.com/...`。
跳转目标是 200 才算真传上去了——只看短链本身返回 302 不够，对象可能在上传时写坏。

## 短链是什么

6 位码（去掉了 `l 0 O 1 I`），访问时 302 到对象存储的真实地址。
真实地址（域名 + 路径）从不进上下文，这就是它存在的理由：一张图一条长 URL，十几张就吃掉几千字符，
而那些字符之后再也不会被用到。

## 出错怎么办

- `401` → token 不对，这时别反复试，直接告主说「上行凭据不对」
- `413` → 超过 50MB，先用 `terminal` 压一下（图片转 webp、视频降码率）再传
- `502` → 服务端连不上 TOS，把返回里的 `error` 原样告他，别自己重试三轮
- 传完文件**不要**顺手把本地文件删掉，他还可能要原始件
