# 上传文件拿短链（upload 工具）

## 一条工具调用

```
upload(path="files/报告.pdf")
```

只返回一行，例如 `https://s.hollway.top/cQ4ygy.txt`。这行就是交付物，直接发给他。

- 文件必须在**沙盒**里（`/work` 下面）：`files/`、`media/`、`shared/` 这些位置。
- 要换显示名（决定扩展名和 Content-Type）：`upload(path="files/x.bin", name="报告.pdf")`
- 上限 **50MB**。超了先压：图片转 webp、视频降码率，再传。

**凭据在框架里，你没有也不需要它。** 沙盒里没有 token 文件，也没有哪条命令能把 token 读出来——
所以别去找，也别自己拼 HTTP 请求，直接用这个工具。

## 不要传什么

桶是**公共读**：任何人拿到 URL 就能看，短链不过期。

- 不能传：凭据、密钥、合同、身份证、出生证明、聊天记录导出
- 想传但拿不准：先问他一句「这个要公开吗」

## 交出去之前先验一次

```
curl -sS -o /dev/null -w "%{http_code} %{redirect_url}\n" <短链>
```

期望 `302` 跳到 `imagevault.tos-cn-guangzhou.volces.com/...`，且跳转目标本身 200。
只看短链返回 302 不够——对象可能在上传时写坏。

## 短链是什么

6 位码（去掉了 `l 0 O 1 I`），访问时 302 到对象存储的真实地址。真实地址从不进上下文，
这就是它存在的理由：一张图一条长 URL 是几百字符，十几张就吃掉几千，而那些字符之后再也不会被用到。

## 出错怎么办

- `上传没配好` → 框架环境里缺 `TOS_SHORT_URL` / `TOS_SHORT_TOKEN`，告他，别自己找
- `401` → token 不对，别反复试，直接说
- `413` / `文件太大` → 超 50MB，先压再传
- `502` → 服务端连不上对象存储，把返回里的 error 原样告他，别自己重试三轮
- 传完**不要**顺手删本地文件，他还可能要原始件
