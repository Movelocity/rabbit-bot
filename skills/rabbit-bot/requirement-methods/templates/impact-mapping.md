# 模板二 · Impact Mapping

来源：Gojko Adzic。用途：**从「为什么做」倒推到「做什么」**，每一层都能被否掉。
花时：1 小时。参加的人：业务方 + 提需求的人 + 干活的人。

## 四层

```
Why  ──── 目标（带数字、带期限）
 ├─ Who  ──── 谁能带来这个变化（是人，不是「用户」）
 │   ├─ How ──── 他要改变什么行为
 │   │   └─ What ──── 所以我们才做什么
 │   └─ How ...
 └─ Who ...
```

## 填法

```
Why（目标）
  <从 X 变到 Y，在 <期限> 前，口径是 <分子/分母/范围>>
  ✗ 「提升效率」「优化体验」  ✓ 「广告费里超预算未发现的比例，从 30% 降到 5%，在 11 月底前」

Who（谁能让它发生）
  <岗位 + 名字，必须是有权限改变行为的人>
  ✗ 「用户」 ✓ 「运营小张」「采购主管」

How（他的行为要变成什么样）
  <一条可观察的行为变化>

What（交付物）
  <为了让他那样做，我们要给什么；一句话，能验收>
```

## 判定规则（硬）

- **`Why` 没有数字和期限 → 整张图不成立**，先回去问。
- **`Who` 没有权限 → 这条分支直接砍。** 最常见死法：指望一个不能改预算的人去控预算。
- **`What` 不得多于 How 的条数**：每个行为变化配一到两个交付物，多了就是想当然。
- 树越宽越危险：3 个 Who 以内。超过就是想一次解决所有事。

## 正例（同一件事）

```
Why：广告超预算未发现的比例从 30% 降到 5%，11 月底前，口径=超预算活动数/在投活动数，按周统计

Who：运营小张（有调预算权限）
  How：每天早会前先看一眼超预算清单，再调价
    What：一页超预算清单，按超支比例倒序，早 8 点前自动刷新

Who：采购主管（没有调价权限，但能停投）
  How：活动超支 > 50% 时收到一条告警，决定是否停投
    What：超 50% 触发一条群消息，带活动名和超支金额
```

反面用法（真实常见）：Why 写「提升广告效率」、Who 写「用户」、How 写「提升体验」、
What 写「做一个数据看板」——四层全是愿望，等于什么都没定。
